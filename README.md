# RNGLab

Research software for the reliability, observability and uncertainty of scientific inference in
stochastic physical systems: how random-source defects, sampler failures, numerical errors and
detector artefacts change the conclusions of Monte Carlo and measurement-based studies.

**Status:** this repository is being set up. The first source snapshot will be added after an
ownership, licence and data review. Until then it contains only this README and the licence.
